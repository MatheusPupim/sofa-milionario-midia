# Mídia do Sofá Milionário

As imagens dos posts ficam aqui por um motivo técnico: a API de publicação do
Instagram não aceita upload de arquivo. Ela exige `image_url` apontando para um
servidor público, e vai buscar a imagem sozinha na hora de publicar.

Quem escreve aqui é `producao/publicar.py`. Não mexa na mão.
